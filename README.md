# MineToo

Небольшой Minecraft-like проект на C++/raylib.

## Editor

В проекте есть отдельный редактор `MineTooModelEditor`.

В нём можно создавать и настраивать анимации для сущностей: игрока, мобов и других моделей.

Также в редакторе есть вкладка **Blocks**, но она пока находится в разработке.
